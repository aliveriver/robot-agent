从以下对话中，提取值得长期记住的内容。

判断标准（满足任意一条才值得提取）：
1. 用户透露了稳定的个人信息（名字、年龄、家庭成员、喜好、不喜欢的事）
2. 发生了有意义的情感事件（生日、伤心、特别开心、完成了某件事）
3. 用户学到了某个知识点，并表现出理解
4. 有值得以后引用的约定或承诺

输出格式（JSON）：
{
  "should_extract": true | false,
  "importance": 0.0 ~ 1.0,
  "memory_text": "一句话描述这段记忆的核心内容",
  "memory_type": "profile" | "episodic" | "knowledge",
  "tags": ["标签1", "标签2"]
}

如果没有值得提取的内容，返回 should_extract: false，其余字段可省略。

对话内容：
{conversation}
